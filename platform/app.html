How this data actually gets built (it isn't a database yet)

Every persona on this page is produced by the same eight-step pass: desk research first, a persona, a journey map, opportunity cards, workflow diagrams only where branching logic exists, a scored matrix, an AI-simulated interview against the gaps, then the findings fed back by hand. Right now that whole pipeline runs as markdown files in a git repo, authored in conversation — this page is a rendered view bolted on afterward, not the system of record. Updating a persona file won't update this page automatically yet.
