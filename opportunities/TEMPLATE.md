# AI Opportunity Card — Template

Every opportunity gets one of these, kept short and comparable across
commodities so they can be rolled into `matrix/`. Adoption fields are
mandatory, not optional — an opportunity card without them isn't finished.

---

**Opportunity name**:

**Persona**: (link to `personas/*.md`)

**Journey stage**: (one of the spine stages in `README.md` — Plan, Monitor,
Decide, Procure, Labour/Equipment, Harvest, Sell, Finance/Compliance, Review)

**Problem** (from the friction table in `journeys/*.md`):

**Current behaviour**:

**AI intervention** — which of these does it do: predict / summarise /
interpret / recommend / automate / coordinate / generate / interact
conversationally / detect anomalies:

**Workflow intervention** (what happens operationally once AI produces its
output — link to a `workflow/*.md` diagram if it needs branching/escalation
logic):

**Human role** (who validates, overrides, or acts on the AI output):

**Adoption barrier — farmer**: (clear benefit? saves time? fits existing
behaviour without a new app? trustable and overridable? works with poor
connectivity?)

**Adoption mechanism — farmer**: (what specifically overcomes the barrier
above)

**Adoption barrier — organisational** (if applicable): (who owns it, who's
accountable when it's wrong, what data/governance/integration it needs)

**Potential value**: (bullet list — e.g. reduced loss, time saved, reduced
input cost, reduced risk)

**Maturity**: Idea / Concept / Pilot / Scaled

**Sources**: (cite `research/sources.md` entries or flag `[VALIDATE]` for
anything not yet grounded)
